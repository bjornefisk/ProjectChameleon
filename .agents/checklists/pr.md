# Pull-request checklist

- [ ] Correct repository, branch, issue, and owner verified.
- [ ] Worktree/diff contains only scoped changes.
- [ ] PR links task and states behavior, non-goals, contract/ADR impact, and risks.
- [ ] Verification commands/results, artifacts, and unrun checks included.
- [ ] Hard validation separated from soft quality/wiring checks.
- [ ] Security, dependency, license, and external-fact notes included where relevant.
- [ ] Required reviewers/checks/code ownership are intact.
- [ ] No force-push, branch-protection bypass, permission escalation, or secret exposure.
- [ ] Review findings resolved or accepted by named owner.
- [ ] Rollback/migration path stated.
