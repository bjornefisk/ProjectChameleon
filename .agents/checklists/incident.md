# Incident checklist

- [ ] Unsafe action stopped; no blind retry or destructive cleanup.
- [ ] Incident category, assets, exposure, time window, and affected refs/artifacts identified.
- [ ] Minimal evidence preserved and sensitive data redacted.
- [ ] Credential/permission containment handled by authorized owner.
- [ ] Affected branch/artifact/environment isolated where authorized.
- [ ] Security/project/release owner notified through approved channel.
- [ ] Scope investigation remained authorized and defensive.
- [ ] Root cause, remediation, regression/monitoring, and communication recorded.
- [ ] Residual risk, owner, and review date assigned.
- [ ] Public issue/PR/release contains no sensitive incident detail.
