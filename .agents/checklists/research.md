# Research checklist

- [ ] Exact question, decision, freshness/version scope, and stop condition written.
- [ ] Local authority and existing evidence read first.
- [ ] External source is primary/official or limitation is recorded.
- [ ] Exact URL/path, revision/version, publisher, dates, and inspected section recorded.
- [ ] Search snippets are not used as final evidence.
- [ ] Material claim corroborated or explicitly marked uncertain.
- [ ] Local reproduction/experiment run when feasible and isolated.
- [ ] Claim labeled `OBSERVED`, `INFERRED`, or `UNVERIFIED_EXTERNAL_FACT`.
- [ ] Contradictions, scope limits, license, platform, and expiry recorded.
- [ ] No secrets/private data were sent to external tools.
- [ ] Researcher did not change product code or silently alter authority.
- [ ] Handoff includes decision impact and next owner.
