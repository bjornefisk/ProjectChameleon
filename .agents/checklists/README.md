# Checklist registry

Checklists are gate evidence, not substitutes for reading authority or exercising behavior. Mark each item `[x]`, `[ ]`, or `[N/A — reason]`; link evidence for every checked gate.

- [`intake.md`](intake.md) — task/risk/ownership preflight.
- [`research.md`](research.md) — source-driven evidence.
- [`web-research.md`](web-research.md) — search/citation/injection gate.
- [`implementation.md`](implementation.md) — owned change and test gate.
- [`verification.md`](verification.md) — observable behavior and artifacts.
- [`review.md`](review.md) — independent correctness review.
- [`security.md`](security.md) — threat/data/supply-chain review.
- [`dispatch.md`](dispatch.md) — parallel agent safety.
- [`pr.md`](pr.md) — GitHub collaboration gate.
- [`release.md`](release.md) — immutable candidate/release gate.
- [`incident.md`](incident.md) — containment and evidence preservation.

A skipped item must have an owner and reason. A green checkbox without a command, source, artifact, or review link is not evidence.
