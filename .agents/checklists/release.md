# Release checklist

- [ ] Candidate revision, platform, artifact digest, and source tree state frozen.
- [ ] Implementation, test/smoke, hard validation, review, security, dependency, and license evidence complete.
- [ ] Native-amd64/offline/other environment claims are sourced or marked unverified.
- [ ] Provenance and generated-artifact state inspected.
- [ ] Open gaps classified as blocker, accepted risk, or external unknown.
- [ ] Release notes, constraints, known gaps, support owner, and rollback written.
- [ ] Required approvals are present.
- [ ] Mutation target/ref/destination verified before action.
- [ ] Resulting tag/release/artifact state re-read and recorded.
- [ ] Monitoring and rollback owner handed off.
