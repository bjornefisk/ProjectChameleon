# Implementation checklist

- [ ] Approved task brief and relevant authority reread.
- [ ] Exact owned paths and sibling changes checked.
- [ ] Callers, interfaces, serialization, fixtures, and failure paths inspected.
- [ ] Failing test/reproduction added or reason it is unnecessary recorded.
- [ ] Minimal change made with repository tools and conventions.
- [ ] No unapproved dependency, runtime, solver, fallback, or scope expansion.
- [ ] Source identity/assets/relationships and hard validation semantics preserved where applicable.
- [ ] Focused success, boundary, invalid, and failure checks run.
- [ ] Changed docs/callers/tests/fixtures updated; obsolete cutover code removed.
- [ ] Diff inspected for unrelated changes, debug output, secrets, stubs, and TODO implementations.
- [ ] Exact checks/results, unrun checks, and next verifier recorded.
