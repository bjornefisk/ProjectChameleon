# Intake checklist

- [ ] Request restated as an observable outcome.
- [ ] Boot instructions, contract, Accepted ADRs, schema, status, roadmap, and final architecture consulted.
- [ ] Current phase and prohibited scope checked.
- [ ] Acceptance criteria and hard invariants written.
- [ ] Non-goals, assumptions, and external facts separated.
- [ ] Affected paths/resources and one owner identified.
- [ ] Risk class: contract / security / dependency / data / GitHub / release / routine.
- [ ] Required role, workflow, capabilities, and data classification chosen.
- [ ] Verification command/smoke path and failure behavior named.
- [ ] Blockers have owner, attempted discovery, and next action.
- [ ] Task/run ID and brief saved.
