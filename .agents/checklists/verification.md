# Verification checklist

- [ ] Acceptance matrix and hard constraints reread.
- [ ] Complete diff and environment assumptions inspected.
- [ ] Focused check run at the highest observable seam.
- [ ] Boundary, invalid, missing-resource, serialization, and fail-closed paths exercised where relevant.
- [ ] Required repository smoke sequence attempted when available.
- [ ] Output artifacts/logs checked for stale, partial, hidden, or misleading results.
- [ ] Exact command, exit status, relevant output, environment, and artifact recorded.
- [ ] Each criterion maps to observed evidence, failure, or explicit unknown.
- [ ] Hard validation separated from soft quality and wiring checks.
- [ ] Tool/environment failures classified instead of converted into product claims.
- [ ] Reviewer/release owner received the verification handoff.
