# Review checklist

- [ ] Review began from contract/acceptance, not the author's conclusion.
- [ ] Complete diff, callers, generated files, fixtures, dependencies, and evidence inspected.
- [ ] Boundary, invalid, ordering, compatibility, concurrency, and rollback risks considered.
- [ ] Tests prove behavior/invariants rather than wiring, copies, source text, or incidental defaults.
- [ ] Security/data/supply-chain concerns routed to specialist where relevant.
- [ ] Every finding has path/symbol, impact, evidence, severity, owner, and disposition.
- [ ] Resolved findings rechecked.
- [ ] Unrun checks and residual risks stated.
- [ ] No finding suppressed for schedule or convenience.
- [ ] Approval status is separate from release approval.
