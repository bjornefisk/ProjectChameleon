# Workflow registry

Workflows are gated procedures. Start at intake, select the smallest path, and record the current gate in the run/handoff.

- `00-intake.md` — classify and bound the request.
- `01-research.md` — local-first source research and web evidence.
- `02-plan.md` — vertical slice and acceptance.
- `03-implement.md` — owned implementation.
- `04-debug.md` — reproduce/root-cause repair.
- `05-verify.md` — observable verification.
- `06-review.md` — independent review.
- `07-github-pr.md` — issue/PR collaboration state.
- `08-release.md` — release qualification and rollback.
- `09-change-control.md` — contract/process/dependency decisions.
- `10-parallel-agents.md` — safe bounded delegation.
- `11-session-handoff.md` — resumable state.
- `12-incident-response.md` — containment and evidence preservation.

A workflow does not override project authority or grant capabilities absent from [`../TOOLING.md`](../TOOLING.md).
