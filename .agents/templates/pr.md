# Pull request record

```text
Title/PR URL:
Task/issue:
Author/owner/reviewers:
Source → target ref:
Candidate revision:

Outcome/behavior:
Non-goals:

Changed paths:

Verification:
- command | exit/result | artifact/evidence
Checks not run/limitations:
Hard validation vs soft quality:
Security/dependency/license notes:
External facts/citations:
Migration/rollback:

Review findings/dispositions:

```

A PR must remain focused and reviewable. Never use it to hide unrelated changes, bypass required checks, or expose secrets.
