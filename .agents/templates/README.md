# Template registry

Templates are evidence forms. Fill them with observed facts and links; do not use blank checkboxes or generic prose as proof.

- [`task-brief.md`](task-brief.md) — bounded request and ownership.
- [`agent-run.md`](agent-run.md) — multi-agent run and child slices.
- [`research-note.md`](research-note.md) — cited research result.
- [`spec.md`](spec.md) — approved design/acceptance.
- [`ticket.md`](ticket.md) — implementation frontier.
- [`handoff.md`](handoff.md) — resumable completed/paused slice.
- [`review.md`](review.md) — independent findings.
- [`adr.md`](adr.md) — durable decision.
- [`experiment-log.md`](experiment-log.md) — reproduction/diagnostic evidence.
- [`issue.md`](issue.md) — GitHub issue.
- [`pr.md`](pr.md) — GitHub pull request.
- [`release.md`](release.md) — release qualification.
- [`incident.md`](incident.md) — sensitive incident record.

Redact secrets, cookies, personal data, and private URLs. Use `OBSERVED`, `INFERRED`, and `UNVERIFIED_EXTERNAL_FACT` labels.
