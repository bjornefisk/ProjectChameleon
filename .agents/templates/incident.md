# Incident record

Store this record in an authorized private location when it contains sensitive details. Public issues/PRs receive only a sanitized reference.

```text
Incident ID:
Detected/updated:
Reporter/lead/security owner:
Classification:

Summary without secrets:
Affected assets/refs/artifacts:
Time window:
Suspected entry/tool/actor:
Exposure/impact:

Containment actions and authorization:
Credential/permission actions (no secret values):
Evidence locations/hashes/redaction:
Affected outputs and last-known-good state:

Root cause status:
Remediation/regression/monitoring:
Communication/notifications:
Residual risk:
Owner/review date:
Closure criteria:
```

Preserve evidence. Do not include tokens, cookies, private keys, personal data, exploit payloads, or unnecessary copies of sensitive content.
