# Capability request

Use when a role needs a capability outside its declared allowlist.

```text
request_id/run/task:
requester/role/owner:
capability and native tool:
target path/resource:
reason and expected evidence:
data classification:

Why lower-risk capability is insufficient:
Scope/bounds:
Security/threat review:
Approval owner/date:
Expiry/revocation:
Observed result/limitations:
Handoff:
```

A request records authorization; it does not create a capability the runtime lacks. Web access requests must follow [`../research/web-search.md`](../research/web-search.md).
